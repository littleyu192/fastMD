# The optional MACE-SOYO model family (fastmd.models.mace_soyo): mace-soyo 0.1.0 (the upstream repository at its
# pinned commit) and cuEquivariance 0.12.0 for CUDA 13, plus the packages `import mace_soyo` needs that a PyTorch
# environment lacks: its package imports torch-sim, which imports tables (with numexpr, blosc2 and their
# dependencies) and declares h5py. Exact versions, each with the sha256 of its file.
# The upstream mace-soyo package requires Python >=3.12,<3.15; do not bypass its Requires-Python metadata.
#
# Platforms: the platform wheels are the Linux aarch64 ones (Grace CPUs, e.g. GB200) for CPython 3.12:
# cuequivariance-ops-torch-cu13, h5py, msgpack, ndindex and numexpr (cp312), tables and blosc2 (abi3), and
# cuequivariance-ops-cu13 (any Python 3). The others are pure Python. An x86_64 environment needs its own hashes for
# those files (a requirement may list several --hash options).
#
# mace-soyo is not on PyPI: its line is the GitHub source archive of commit 387b5114c974fb04b8aceffac82d1d8f10ea4ac0
# (the commit Matbench Discovery pins), built without build isolation by the base environment's setuptools
# (>= 77.0.3, as its pyproject.toml requires).
#
# Install over an environment that already runs FastMD, in a virtual environment that sees its packages:
#
#   python -m venv --system-site-packages <venv>
#   <venv>/bin/python -m pip install --no-deps --no-build-isolation --require-hashes -r requirements-mace-soyo.txt
#
# This is the upstream MD test-environment manifest, not a portable FastMD installer. Its CI lane is not
# distributed here. Other Python, architecture or CUDA combinations need separately verified wheels and hashes.
# Install in an isolated environment; do not replace an existing model environment's PyTorch/cuEquivariance stack.
#
# Deliberately not installed, the base environment provides them: torch, numpy, ase, nvalchemi-toolkit-ops,
# warp-lang and triton (the versions FastMD runs with stay in place; mace-soyo's own pins of torch 2.12.0,
# warp-lang 1.13.0, numpy >= 2.4.6, the CUDA 12 cuEquivariance kernels and exact scipy, PyYAML, tqdm and cffi
# versions are not followed), nvidia-cublas, a dependency of cuequivariance-ops-cu13 (the base environment's CUDA 13
# cuBLAS and NVRTC are used), and the other dependencies of these packages: scipy, sympy, networkx, packaging, tqdm,
# platformdirs, nvidia-ml-py, PyYAML, pydantic, httpx, rich and typing-extensions. mace-soyo's training dependencies
# (torch-geometric, torch-ema, lmdb, ase-db-backends, opt_einsum_fx) are not needed to run its model.
